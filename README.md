# DevOps Git Project

## Project Overview

This project demonstrates DevOps version-control practices using Git and GitHub.

## Objectives

* Learn Git version control
* Create and manage branches
* Use feature branches
* Create Pull Requests
* Merge changes safely
* Use `.gitignore`
* Create Git tags
* Document project tasks using Markdown

## Technologies Used

* Git
* GitHub
* Markdown

## Branching Strategy

### main

Contains stable and final versions of the project.

### dev

Contains development work before it is merged into `main`.

### feature/*

Used for developing individual features.

## Git Workflow

```text
feature branch
      ↓
     dev
      ↓
    main
```
